# 启明 Qiming · 可验证不变量清单

> 每个模块至少有 1 条可被独立实现交叉验证的「不变量」——解析解 vs 数值解、
> 暴力枚举 vs 现成库、参照实现 vs 主实现、手算金标准 vs 实现。
> 这是启明对"世界顶级"的操作性定义：**不是说得快，而是验得穿。**

运行方式：

```bash
python -m qiming.cli selftest   # 26 项内联不变量，零网络，秒级
pytest tests/                   # 72 项 pytest（hermetic：零网络零模型）
python -m benchmarks.bench      # 黄金语料端到端评测
```

## 1. 嵌入层（embeddings.py）

| 编号 | 不变量 | 验证方法 |
| --- | --- | --- |
| I-E1 | 输出形状 == (n, dim)，dtype float32 | 直接断言 |
| I-E2 | 每行 L2 范数 == 1（内积即余弦） | `np.allclose(norms, 1)` |
| I-E3 | 同文本重复编码逐位一致（确定性） | `np.array_equal` |
| I-E4 | 自相似度 == 1 | 点积断言 |
| I-E5 | 相关文本相似度 > 无关文本相似度 | 语义模型可用时执行，否则 skip |

## 2. 分块层（chunking.py）

| 编号 | 不变量 | 验证方法 |
| --- | --- | --- |
| I-C1 | 每块长度 ≤ chunk_size | 直接断言 |
| I-C2 | 相邻块重叠 ∈ [0, chunk_overlap + max_separator] | 实测尾部/头部公共串 |
| I-C2b | 长文本至少存在一处重叠（上下文连续） | 存在性断言 |
| I-C3 | 无内容丢失：Σ块长 ≥ 原文长 − chunk_overlap | 求和断言 |
| I-C4 | 无空白块 | 直接断言 |

> 注：I-C2 表述为"不超预算"而非"恒等于 chunk_overlap"——LangChain 合并
> 策略在自然边界丢弃不足一个 split 的尾部，实际重叠 ∈ [0, 预算]。
> 这是对 RecursiveCharacterTextSplitter 真实行为的精确刻画。

## 3. 稀疏检索层（sparse.py）

| 编号 | 不变量 | 验证方法 |
| --- | --- | --- |
| I-S1 | BM25 得分 == Okapi 公式手算值（±1e-9） | 英文微型语料，手工推导（见测试 docstring） |
| I-S2 | 查询词全部命中的文档排第一 | 直接断言 |
| I-S3 | 空库检索返回 []，不抛异常 | 边界测试 |
| I-S* | rank_bm25 与内置参照实现排名一致 | 交叉验证（多查询） |

手算金标准推导（I-S1）：

```
语料: d1 = "password reset mail", d2 = "weather forecast today"
查询: "password reset"
N = 2, df = 1, avgdl = |d1| = 3, k1 = 1.5, b = 0.75
idf = ln(1 + (N − df + 0.5)/(df + 0.5)) = ln 2
项分 = idf · f(k1+1)/(f + k1(1 − b + b·|d|/avgdl)) = ln2 · 2.5/2.5 = ln 2
score(d1) = 2·ln 2 ≈ 1.3862943611198906
```

## 7. 可验证性层（verify.py）——创新内核

| 编号 | 不变量 | 验证方法 |
| --- | --- | --- |
| I-X1 | 回答逐字摘自某证据 → coverage = 1.0；每句均逐字相同 → faithfulness = 1.0 | 构造性断言 |
| I-X2 | 回答与证据完全无关 → coverage ≈ 0，拒答 | 构造性断言 |
| I-X3 | 引用编号越界 → citations_valid = False | 构造性断言 |
| I-X3b | 被引证据对所有句子均无支持（张冠李戴）→ 判无效 | 构造性断言 |
| I-X4 | 空证据 → 直接拒答 | 边界测试 |
| I-X5 | 校验器纯函数：同输入必同输出 | 双次调用比对 |
| I-X6 | 半句有据半句编造 → coverage = 0.5 < 0.6 → 拒答 | 构造性断言 |

## 9. 基准评测（benchmarks）

黄金语料 25 篇（星尘协作平台）+ 黄金问答 21 条（18 可答 + 3 应拒答）：

| 指标 | 含义 |
| --- | --- |
| hit@1 / hit@4 | 目标文档排第一 / 进入引用列表的比例 |
| MRR | 目标文档排名倒数的平均 |
| 有据回答率 | 可答问题通过校验的比例 |
| 拒答率 | 应拒答问题被拒答的比例 |

结果写入 `benchmarks/results.json`，含当时全部后端快照（嵌入模型、
索引类型、重排器、LLM、全部配置），保证**任何人在任何时间可复现**。
